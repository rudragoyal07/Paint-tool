# 🎨 Paint Tool

A modern web-based **Paint Tool** built using **HTML, CSS, and JavaScript**. This project provides an interactive drawing canvas where users can sketch, draw shapes, add text, customize fonts and colors, and save their artwork. It was developed as part of my college Winter Assignment and is deployed on Netlify.

🌐 **Live Demo:** https://paint-tool-by-rudra.netlify.app/

---

## 📌 Features

- ✏️ Pencil Tool
- 🖊️ Pen Tool
- ✍️ Sketch Tool
- 📝 Add Text on Canvas
- 🔷 Draw Shapes
  - Circle
  - Square
  - Rectangle
  - Triangle
  - Oval
- 🎨 Multiple Color Options
- 🔤 Multiple Font Styles
- 🔠 Adjustable Font Sizes
- ↩️ Undo Functionality
- ↪️ Redo Functionality
- 💾 Save Drawing
- 📱 Responsive Design (Mobile Friendly)

---

## 🎯 How to Use

1. Open the website.
2. Click **"Start Creating"**.
3. Select a drawing tool.
4. Choose your preferred color.
5. Select a shape (optional).
6. Change font style and size for text.
7. Draw freely on the canvas.
8. Undo/Redo changes whenever needed.
9. Save your artwork.
